## Conventions established

- **Shared content inset — superseded 2026-09-16**: no longer `mx-auto max-w-[1722px] px-6 lg:px-[99px]`. Now pure `vw`-fluid: horizontal insets expressed as `vw` derived from a `1920` reference (e.g. `5.15625vw` for the `99px`-at-1920 content edge inset), applied uniformly at every viewport width with no breakpoint gating — see `Header.tsx`'s `paddingLeft`/`paddingRight` and `BackgroundLines.tsx`'s `INSET_VW` for the pattern. Reuse *this* for any new section, don't reintroduce the old `max-w` convention — it caused a real, user-reported bug (grid/header drifting apart, asymmetric margins) on non-1920 screens. If a section ever needs Figma-derived px positions inside its own content, convert with the same `vw(px) = (px / 1920) * 100 + 'vw'` helper, or a fraction (`px / referenceWidthPx`) if it needs to live inside an SVG/`objectBoundingBox` mask.
